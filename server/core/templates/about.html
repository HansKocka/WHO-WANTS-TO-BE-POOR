ABOUT

Who Wants To Be Poor is a real-time quiz game inspired by Kahoot.
Players can join a game using a PIN, answer questions, and compete for the highest score.
A host creates and starts a quiz
Players join using a game PIN
Questions are sent in real-time
Players answer and earn points
Tech stack
Django + Django Channels
WebSockets (real-time communication)
SQLite
This project was created to learn real-time web applications and WebSocket communication.
